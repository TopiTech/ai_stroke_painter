AI Stroke Painter Pro v1.1.0 Enhanced

Krita 上で、プロフェッショナルな本格イラスト・アニメ線画・風景・エフェクト・幾何学アートの描画計画を生成し、マルチレイヤーへ自動分割して筆圧付きストロークを描画する AI ペイントプラグインです。

🌟 主な機能とカスタマイズ性

1. 本格プロシージャル・イラストエンジン (Offline)

アニメ美少女・少年の顔、風景（山・樹木・北斎風大波・水墨画・花）、集中線・カケアミ・魔法陣、マンダラ、動物（猫・犬・鳥・ドラゴン）を完全オフラインで生成。

12種カラーパレット (アニメ、モノクロ、サイバーパンク、自然、パステル、水彩、レトロポップ、ダークファンタジー、セピア、ボタニカル、水墨画、サイバーゴールド)
8種ブラシプロファイル (自動、Gペン、丸ペン、毛筆、マーカー、鉛筆、透明水彩、エアブラシ)

2. 参照画像の読み込み & 画像解析 (Image-to-Stroke)

画像の連結輪郭・立体感陰影・カラーを解析し、縦横比と透過領域を保った手描き風ストロークへ自動変換。微小ノイズの除去と深層クロスハッチングに対応。

  • エッジ感度: 0.02〜0.50（微細な質感〜大胆な主線）
  • 立体感ハッチング: 標準、高密度、低密度、オフ（最暗部でのクロスハッチング対応）
  • 下塗り描画: ON / OFF
  • カラーモード: 元画像カラー / パレット近似マッピング

3. 🖌️ ブラシ・描画 & レイヤー・アンドゥ統合

  • Krita アンドゥ（Undo/Redo）マクロ統合: 1回の描画セッション全体を 1 つのアンドゥ単位として記録。Ctrl+Z 1回で全レイヤーの描画を一括アンドゥ/リドゥ可能。
  • 太さ倍率: 0.1x 〜 5.0x / 不透明度: 10% 〜 100%
  • レイヤー出力: 実行ごとの一意なマルチレイヤーグループ / アクティブレイヤー直接描画 / 単一新規レイヤー
  • 出力グループ / レイヤー名: 自由設定
  • 画面更新間隔: 5 〜 100線分ごと

4. 🤖 OpenAI 互換 LLM / Vision & 自律反復改善 (Auto-Refine)

Claude 3.7 / GPT-4o / Gemini 2.0 / DeepSeek-R1 等の Chat Completions 互換 API と連携。各中間ステップのキャンバスを視覚評価しながら下塗り→陰影→主線→消しゴム彫刻→仕上げと段階的に描き進めます。

  • 消しゴム彫刻 ('is_eraser': true): 輪郭の修正やハイライト彫刻の自律指示に対応
  • Temperature & Top-P: サンプリング調整
  • Reasoning Effort: 思考モデルの思考強度制御
  • Vision 解像度: 256, 512, 768, 1024 px
  • 追加カスタム指示: ユーザー独自の描画指示をシステムプロンプトへ追加

プライバシー: Auto-Refine ではキャンバス画像を設定先 API へ送信します。API Key を使う外部接続は HTTPS 必須で、HTTP はローカル接続だけ許可されます。API Key は設定へ保存されません。

5. 💾 プリセット管理 & デバッグ

  • 12種のビルトインプリセット
  • カスタムプリセット保存 (💾) & 削除 (🗑️): 現在の設定を QSettings へ永続保存
  • 📤 プリセットの JSON 入出力 (Import / Export): カスタムプリセットのファイル保存・読み込み共有に対応
  • 初期設定リセット (🔄)
  • 🐞 デバッグモード: 通信ログのリアルタイム表示、コピー、保存

🚀 クイックスタート

  1. Krita で新規キャンバスを開きます。
  2. Docker 上部のクイック・プリセットからモチーフを選択（例: 「👤 美少女アニメ顔」「🌸 透明水彩の野花」）。
  3. 🎨 AIストロークを描画 をクリックします。

通常は「マルチレイヤー分割」または「単一新規レイヤー」を推奨します。これらは停止・描画失敗時に今回の生成物を除去します。「アクティブレイヤー直接描画」は既存レイヤーを変更するため、自動ロールバックできません。
