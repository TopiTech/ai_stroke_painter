AI Stroke Painter MVP

筆圧付きストロークを Krita のペイントレイヤーへ描画する MVP です。オフラインのルールベース Planner と OpenAI 互換 LLM を選べます。

使い方

  1. ドキュメントを開き、使いたいブラシと前景色を選択します。
  2. 設定 → ドッキングパネル → AI Stroke Painter MVP を表示します。
  3. 指示、Seed、本数を設定し、AIストロークを描画 を押します。

「髪」または「S字」を含む指示は髪の毛風のカーブになります。同じ指示、Seed、本数、キャンバス寸法では同じ計画を作ります。

結果と停止

描画先は AI Strokes (editable) レイヤーです。すでに同名のレイヤーがあれば再利用します。停止を押すと、現在の線分の安全な境界で描画を終えます。結果は通常のペイントレイヤーなので、Krita のレイヤー操作・消しゴム・Undo で編集できます。

既定では schema version 付きの計画 JSON をユーザーデータ領域に保存し、保存先を Docker に表示します。

OpenAI 互換 LLM

Planner で OpenAI 互換 LLM を選び、Base URL（例: https://api.openai.com/v1）、Chat Completions 対応の Model、API Key を入力します。API Key 欄が空の場合は OPENAI_API_KEY 環境変数を使います。キーは保存しません。

指定した API に指示とキャンバス寸法を送信し、/chat/completions の JSON 応答を描画計画として検証します。スキーマ、本数、座標、筆圧が不正な応答は描画しません。LLM モードの Seed は完全な再現性を保証しません。

制約

現在のブラシプリセットと前景色で描画します。ブラシの自動切替、画像生成、VLM 評価、連続ネイティブストロークは含みません。描画は Node.paintLine の短い線分列による近似のため、ブラシや Krita のビルドによって見た目と Undo 粒度が変わる場合があります。
