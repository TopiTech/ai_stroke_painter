[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](COPYING)

**AI Stroke Painter** は、Krita の本格的なデジタルペイント基盤をネイティブ C++ アプリケーションとして再構成した、次世代の **AI イラスト制作統合環境** です。

従来の Krita プラグインや Python (PyKrita) スクリプトではなく、C++ ネイティブで極めて高速に動作します。単に完成画像をキャンバスに貼り付ける一般的な画像生成ツールとは異なり、**LLM（大規模言語モデル）が生成した幾何座標と作画戦略に基づき、絵筆のストロークをレイヤー別（下塗り・陰影・線画・ハイライト・特殊効果）に物理描画** します。

生成されたイラストは完全なレイヤー構造を保持しているため、Krita の多彩なブラシ・消しゴム・投げ縄選択・カラーパレットを用いて、クリエイター自身が直感的に手動加筆・修正・仕上げを行うことができます。

## 🌟 主要な特徴

- **ネイティブ C++ 実行**: Python や PyKrita に一切依存せず、Krita の強力な描画エンジン・カラーマネジメント・元に戻す/やり直す（Undo/Redo）を直接高速活用。
- **レイヤー別ストローク描画**: AI が `Flats`（下塗り）、`Shading`（陰影・乗算）、`Lineart`（線画）、`Highlights`（ハイライト・スクリーン）、`FX`（効果・加算）を別々の独立したレイヤーとして自動構築。
- **統合スタートページ (Welcome UI)**: キャンバス未作成時にもワンクリックで作成可能な Omnibar プロンプト入力バー、クリップボードからの即座な展開 (`Ctrl+V`)、6種のスタイルプリセット、最近使った作品のリアルタイム自動同期を完備。
- **自律多段階作画 (Goal モード)**: AI が自らの描画結果を視覚的に自己分析・批評し、指定した目標完成度（60–98%）に達するまで自律的にブラッシュアップを反復。
- **マルチモーダル参照画像 (Reference Image)**: ファイル、クリップボード、または現在のキャンバスから参照画像を添付可能。16,384px/24Mpx安全ガード、白背景アルファ合成、自動アスペクト比維持リサイズにより、Vision LLM にキャラクターの衣装・髪型・ポーズ・配色を安全かつ的確に参照させることが可能。
- **Simple / Pro 2モード UI**: 気軽にアイデア出しができる「かんたん (Simple)」モードと、ストローク予算・トラッピング幅・サンプリング温度まで細かく追い込める「詳細 (Pro)」モードを瞬時に切り替え。
- **ビジュアルカード選択**: 画風（アニメ・水彩・厚塗り等7種）、構図・アングル（顔アップ・全身等4種）、照明（昼光・夕暮れ等4種）を直感的なボタンで即座に適用。
- **高度な AI 推敲 (Prompt Expander)**: OpenAI・DeepSeek・Google Gemini・Anthropic Claude の各形式に対応し、推論モデルの思考タグ（`<think>`）や Markdown フェンスを自動除去して高品質な作画プロンプトへ展開。
- **物理レンダリング (Linear HDR 32-bit)**: RGBA16F 浮動小数点バッファと線形 sRGB 空間での W3C レンダリングに加え、加算合成 (`blendAdd` / linear_dodge / plus) に完全対応し、暗部バンディングや色相ドリフトを極限まで抑制。
- **徹底したセキュリティ**: API キーは Windows DPAPI により暗号化保存。さらにログ出力や UI エラー表示から各種 API キー（OpenAI, Gemini, GitHub PAT 等）やトークンを自動で完全マスキング。

### 統合スタートページ (Start Page)

キャンバスを開いていない起動直後には、中央作業エリアに統合スタートページが表示されます：

1. **Omnibar プロンプト入力バー**:
   - 画面上部の入力欄にプロンプトを入力し、`Enter` キーまたは **「⚡ 生成して開く」** を押すだけで、1024×1024 の最適キャンバスが即座に作成され、AI 生成が自動開始されます。
   - 日本語などの IME 変換確定キー（Enter）による誤送信を防止する安全機構（`returnPressed` 厳密連動）を搭載。
2. **クイックスタートカード (Primary Actions)**:
   - **🎨 新しいキャンバス (`Ctrl+N`)**: カスタム寸法や色空間を指定して作成。
   - **⚡ AI クイックキャンバス (`1024x1024`)**: 最適な正方形キャンバスを瞬時に展開。
   - **📂 画像・作品を開く (`Ctrl+O`)**: 既存の `.kra`、PNG、PSD などをロード。
   - **📋 クリップボードから (`Ctrl+V`)**: コピーした画像をワンクリックで新規キャンバス化（巨大画像の自動安全クランプ付き）。
3. **クリエイティブスタイル プリセット (ワンクリック開始)**:
   - `🖋️ Anime & Manga Line Art`: 彩色なし・高精細ペンタッチの純粋なインク線画と塗り絵
   - `🌸 Anime Cel-Shading`: 繊細なベクター主線と鮮やかなセルアニメ調着彩
   - `🌆 Cyberpunk & Scifi`: ネオンライトと大気感のあるコンセプトアート
   - `🖌️ Watercolor & Atomic Ink`: 物理シミュレーションによる滲み・水彩タッチ
   - `📐 Vector Geometric Art`: 精密な幾何学パスとストロークグラフ描写
   - `🎲 Surprise Me! (お題生成)`: ランダムなインスピレーションプロンプトで即開始
4. **最近の作品 (Recent Artworks)**:
   - 直近で開いたファイル履歴をリアルタイム同期表示（クリックまたは `Enter` で即オープン、履歴クリア機能付き）。
5. **AI クリエイティブガイド ＆ ショートカット**:
   - 作業効率を高めるヒントやキーボードショートカット一覧を常設表示。

## 🚀 クイックスタート

### ワンクリック起動

リポジトリ直下のバッチファイルからワンクリックで起動できます。

```bat
run-ai-stroke-painter.bat
```

> [!TIP]
> `CRAFT_ROOT` 環境変数が未設定の場合は自動で `C:\CraftRoot` が利用されます。カスタム環境で実行する場合は事前に `set CRAFT_ROOT=D:\CustomCraft` などのように指定できます。
>
> 手動で PowerShell から起動する場合は以下のコマンドを実行してください：
> ```powershell
> $craftRoot = if ($env:CRAFT_ROOT) { $env:CRAFT_ROOT } else { 'C:\CraftRoot' }
> $packageBin = "$craftRoot\ai-stroke-painter\bin"
> $env:PATH = "$packageBin;$craftRoot\bin;$craftRoot\mingw64\bin;" + $env:PATH
> $env:QT_PLUGIN_PATH = "$craftRoot\plugins"
> $env:QT_QPA_PLATFORM_PLUGIN_PATH = "$craftRoot\plugins\platforms"
> & "$packageBin\ai-stroke-painter.exe"
> ```

### 最速チュートリアル (スタートページ / Simple モード)

1. アプリを起動します。
2. **スタートページ中央の Omnibar** に描きたい情景（例: `月夜に佇む銀髪の魔法使いのアニメ調イラスト`）を入力し、`Enter`（または「⚡ 生成して開く」ボタン）を押します。
   - または、右側パネルのチップ（`美少女`, `桜風景`, `サイバー` 等）をクリックしてプロンプトを入力し、**「🎨 生成してレイヤーに追加」**（または `Ctrl+Enter`）を押します。
3. 生成が完了すると、キャンバスとレイヤーパネルに `Flats`, `Shading`, `Lineart`, `Highlights`, `FX` が自動構築されます！

---

### こだわりチュートリアル (Pro モード)

1. 右側上部のタブを **「🛠️ 詳細 (Pro)」** に切り替えます。
2. **「▶ 詳細設定（エンドポイント / API キー）」** を展開し、利用する LLM の設定を入力します：
   - **エンドポイント**: `https://api.openai.com/v1/chat/completions` 等
   - **モデル**: `gpt-4o`, `o3-mini`, `deepseek-chat`, `gemini-2.5-flash` など
   - **API キー**: プロバイダーの API キー（Windows では「🔑 API キーをこの端末に保存する」を有効にすると DPAPI で安全に保存されます）
3. 高度な描画パラメータを微調整：
   - **ストローク予算 (Stroke Budget)**: 線の密度と細部描き込み量（20〜4,000本、既定: 500本）
   - **トラッピング幅**: 線画と下塗りの境界の白抜けを防ぐ塗り拡張幅（既定: 1.5 px）
   - **知覚自動補正 (Perceptual Repair)**: 下塗りの塗り残し穴や顔の斜線ノイズを自動修復
   - **物理レンダリング**: 有効化すると Linear HDR 32-bit 浮動小数点演算で描画
4. **「🎨 生成してレイヤーに追加」** を実行します。

## 🎯 自律描画エージェント (Goal Agent モード ＆ Refinement Loop)

**Goal モード** は、固定された手順の自動実行にとどまらず、LLM の自律的思考と視覚観察を最大限に活かした **「描画専用自律エージェント (StrokeAgent)」** へと進化しました。
AI は毎ステップ自らキャンバスを観察・批評し、意図と戦略を思考し、工程を能動的に立案・調整しながら、プロのイラストレーターのように最高品質のストロークを重ねていきます。

### Goal Agent の基本アーキテクチャと設計思想

一般的な画像生成 AI では「完成画像が一度に出力されて終わり」であり、クリエイターが作画の途中に介入したり、制作過程を共有したりすることは困難でした。AI Stroke Painter の Goal Agent は以下の認知ループアーキテクチャによりこれを根本から革新しています：

```text
[プロンプト・参照画像 ＋ 人間からのフィードバック]
                    │
                    ▼
     ┌──────────────────────────────┐
     │ 1. 視覚観察 (Observation)    │◄── 768px Vision スクリーンショット ＆ 累積幾何要約
     └──────────────┬───────────────┘
                    ▼
     ┌──────────────────────────────┐
     │ 2. 自律思考 (Reasoning)      │◄── 構図・立体感・色彩調和の意図を言語化
     └──────────────┬───────────────┘
                    ▼
     ┌──────────────────────────────┐
     │ 3. 工程立案 (Phase Planning) │◄── 次のアクション・残りステップ数の動的見積もり
     └──────────────┬───────────────┘
                    ▼
     ┌──────────────────────────────┐
     │ 4. 職人技描画 (Craftsmanship)│◄── Catmull-Rom スプライン・多階層陰影・線画階層
     └──────────────┬───────────────┘
                    ▼
     ┌──────────────────────────────┐
     │ 5. 自己評価 (Readiness Eval) │◄── 完成度スコア採点 ＆ ゴール達成判定
     └──────────────┬───────────────┘
                    │
           [ゴール判定] ── 未達成 ──► [自律ブラッシュアップ (Refinement Round)]
                    │                    (消しゴム補正・外科手術的微小ディテール清書)
                    ▼ 達成 (または人間が早期確定)
                🏁 作品完成！
```

1. **認知的自律思考 (`agent_thought`)**:
   エージェントは単に座標を出力するのではなく、キャンバスの状態を観察した結果（`observation`）、この工程で何をすべきかという芸術的理由（`reasoning`）、現在のフェーズと次に予定する工程（`current_phase`, `planned_next_phase`）、残り必要ステップ数の自律見積もり（`estimated_remaining_steps`）を自ら思考して言語化します。
2. **Vision In The Loop (マルチモーダル自己認識)**:
   各ステップの開始時、現在のキャンバス状態が自動的に解像度 768px の Vision 画像としてエンコードされ、LLM に入力されます。AI は「いまキャンバスに何が描かれ、何が足りないか」を自らの目で観察しながら、次の作画戦略を決定します。
3. **人間と AI の協調介入 (Human-in-the-Loop Feedback)**:
   ステップごとの一時停止中、クリエイターはキャンバスへの直接加筆だけでなく、「髪の影をもう少し柔らかく」「瞳のハイライトを強調して」といった指示テキストを入力できます。エージェントは過去の思考コンテキストを引き継ぎつつ、`user_feedback_response` で指示に応えながら次のストロークを生成します。
4. **プロンプト第一原則 (Prompt-First Principle)**:
   多段階の作画途中で AI が元の指示から逸脱しないよう、毎ステップのリクエストに `restated_goal` として元のプロンプトが最優先ディレクティブとして再注入されます。

### 作画フェーズと動的工程立案

エージェントは描画対象（キャラクター、風景、メカ、アニメ風、水彩画等）に合わせて最適な工程を動的に選択・立案します。

#### 1. 標準 4段階プラン (通常のアニメ・イラスト制作)
最もバランスの良い標準的な制作フローです：
- **Step 1: Flats & Background (下塗り ＆ 背景)**
  - 白抜けのないシームレスなベース幾何を形成。キーライト色とアンビエントシャドウ色を調和させ、以降の線画・陰影が正確に位置合わせ（Registration）できるランドマークを構築。
- **Step 2: Shading & Ambient Occlusion (3D陰影 ＆ 環境遮蔽)**
  - `Shading` レイヤー（乗算）に描画。光源ベクトルに基づき、顎の下・髪の落ち影・服のシワ・鼻筋の立体感を陰影づけ。肌の血色やチーク（SSS / 表面下散乱）もここで配置。
- **Step 3: Lineart & Details (精密線画 ＆ 解剖学的ディテール)**
  - `Lineart` レイヤーに描画。美しい入り抜きを持つ Catmull-Rom スプライン曲線を用い、瞳（上まつ毛のアーチ、瞳孔、虹彩輪郭）、唇、髪房の流線、衣服のテンションラインを精緻に作画。純黒を避け、深みのある濃紺や焦茶のインク色を自動選定。
- **Step 4: Highlights & FX Polish (鏡面ハイライト ＆ 仕上げ)**
  - `Highlights`（スクリーン）および `FX`（加算）レイヤーに描画。瞳のキャッチライト（#FFFFFF）、天使の輪（ヘアハイライト）、リップのグロス光、大気光・リムライトを配置して完成。

#### 2. 18段階マスターワークセッション (1-Hour Masterwork)
ステップ数を最大（18段階）に設定することで、プロが1時間かけてじっくり描くような極限の描き込みセッションが展開されます：
1. 構図立案・プロポーション・キャンバスレイアウト (`Composition & Proportions`)
2. 大気背景ウォッシュ・地平線グラデーション (`Atmospheric Background Wash`)
3. 環境構造・中景建築 (`Environment Structures`)
4. キャラクターシルエット・ベースブロッキング (`Character Silhouettes`)
5. 肌ベース下塗り・インナー (`Flat Coloring - Skin Base`)
6. 髪房下塗り・アウター衣装 (`Flat Coloring - Hair & Costume`)
7. 主陰影・大域光源ベクトル (`Primary Form Shading`)
8. 2次落ち影・アンビエントオクルージョン (`Cast Shadows & AO`)
9. 表面下散乱 (SSS)・血色ウォッシュ (`Subsurface Scattering & Blush`)
10. 構造ラフ輪郭・特徴位置合わせ (`Structural Contours`)
11. 精密マイクロインク・瞳と表情 (`Micro-Inking - Eyes & Expression`)
12. 精密インク・外輪郭シルエット (`Precision Inking - Silhouettes`)
13. 精密インク・髪の流れとスプライン (`Precision Inking - Hair Strands`)
14. 精密インク・衣服のシワとドレーパリー (`Precision Inking - Cloth Folds`)
15. 繊細なハッチング・交点フィレット (`Form Hatching & Corner Fillets`)
16. 主拡散ハイライト・天使の輪 (`Diffuse Highlights & Hair Halo`)
17. 鏡面ハイライト・リップ・瞳キャッチライト (`Specular Glints & Eye Catchlights`)
18. 大気リムライト・ブルーム・マスターワーク仕上げ (`Rim Light & Bloom Polish`)

#### 3. 純線画 (Pure Line Art) 専用シーケンス
着色を行わず、インクペンによる描画に特化したシーケンスです。Gペンの抑揚、鋭いハネ、瞳の書き込み、顎下の平行ハッチング、交点フィレット（インク溜まりシミュレーション）などを段階的に清書します。

### 目標完成度 (Readiness) と自律ブラッシュアップ (Refinement Loop)

基本の作画ステップ（例: 4ステップ）が終了した時点で、エージェントは自らの描画結果を視覚批評し、完成度（`readinessScore`: 0.0〜1.0）を算出します。

1. **自律ゴール到達判定 (`isGoalQualitySatisfied`)**:
   以下の条件がすべて満たされた場合に「ゴール達成」と判定され、作画が自動完了します：
   - AI 自身の判定フラグ `goalReached == true`
   - 自己評価完成度 `readinessScore >= 目標完成度 (既定: 85%)`
   - 構造品質スコア `completionScore >= 0.60` (60%)
   - 有効なストローク操作が存在すること
2. **外科手術的欠陥修正 (Surgical Defect Correction)**:
   目標完成度に満たない場合、エージェントは自動的に **自律ブラッシュアップ（Refinement Round）** に移行します。
   - 新しい絵を最初から描き直すのではなく、過去の批評領域（Critique Regions）を元に、「瞳のキャッチライトのズレ」「顎のラインの乱れ」「下塗りの微小な隙間」などの欠陥部位のみをピンポイントで修正。
   - **消しゴムストローク (`is_eraser: true`)**: 線画のはみ出しや余分な重なりを、消しゴムストロークで削り取って整える高度な補正を実行。
3. **暴走防止用上限ステップ数 (Safety Step Limit)**:
   目標完成度が高すぎる場合や、AI が完璧を追求して無限ループに陥るのを防ぐため、安全上限ステップ数（10〜60ステップ、既定: 36ステップ）を設定可能。この上限に達した場合は安全に作画を締めくくります。

### 🤖 自律描画エージェント・インスペクター (リアルタイムUI)

作画中、AI Illustration パネル内には専用の **Goal Agent インスペクター** が展開され、エージェントの思考プロセスがリアルタイムに表示されます：

- **作画フェーズ表示**: 「🎯 工程 2/4 (3D SHADING & FORM VOLUMES)」や「🎯 自律ブラッシュアップ (ステップ 5)」など、現在の工程を明示。
- **👀 キャンバス観察 (Observation)**: 「下塗りベースは均一にカバーされたが、首元の落ち影と瞳の瞳孔が未描画である」など、現在のキャンバス状態の視覚分析結果。
- **🧠 意図 ＆ 作画戦略 (Reasoning)**: 「顔の立体感を出すため、顎下に2段階の乗算シャドウを配置し、瞳の虹彩輪郭を清書する」といったエージェントの意図。
- **🔮 次回予定アクション (Next Action)**: 「次回: 髪房のハイライトと外輪郭の微細インク清書」など、次に計画しているアクション。
- **🎯 着目領域 (Focus Area)**: AI が現在重点的に描き加えている部位（例: 「Face & Expression」）。
- **自律完成度ゲージ (Readiness Bar)**: エージェント自身が判定した現在の仕上がり具合（0〜100%）をグラデーションプログレスバーで表示。
- **💬 エージェントへの指示・要望 (Human-in-the-Loop Feedback)**:
  一時停止中にユーザーが直接指示を書き込めるテキストボックス。エージェントは次ステップのリクエストでこれを受け取り、指示に応じた作画を行います。

### 人間と AI の協調作画（ステップごと一時停止 ＆ 早期確定）

AI Stroke Painter は、AI の全自動出力だけでなく **「クリエイターと AI のペアペインティング」** を強力にサポートします。

1. **段階ごとに一時停止（手動加筆・確認を待つ）**:
   - このオプションをチェックしておくと、各ステップ（例: 下塗りが終わった段階）でエージェントが自動停止します。
2. **手動加筆 ＆ 指示入力**:
   - 待機中、クリエイターは Krita のブラシ (`B`) や消しゴム (`E`)、投げ縄選択を使ってキャンバスに直接加筆・修正を行えます。
   - 同時にインスペクター内の「💬 エージェントへの指示・要望」欄にメッセージを追記できます。
3. **「▶ 次のステップへ進む」 (`Ctrl+Enter`)**:
   - 準備ができたらボタンを押すか `Ctrl+Enter` を入力します。エージェントは手動加筆されたキャンバス画像と指示メッセージを同時に認識し、自然に調和するストロークを生成します。
4. **「🏁 ここで完成」 (早期確定)**:
   - 設定したステップ数や目標パーセンテージに達していなくても、「この段階の雰囲気がとても気に入った」という場合は、いつでもこのボタンを押して作画をその場で確定・終了できます。

---

### エラー自動回復・フォールバック機構

長時間の多段階セッションを安定して完走させるため、高度な耐障害設計が備わっています：

- **一時的ネットワーク障害の自動リトライ (Exponential Backoff)**:
  API のレート制限（429）やサーバー一時エラー（500〜504）、DNS・TLS ハンドシェイク失敗を検知した場合、指数バックオフで自動再試行。
- **Vision Fallback (自動画像フォールバック)**:
  画像ペイロードが大きすぎることによるプロバイダー側エラーや Vision API 制限に遭遇した場合、自動的に「テキスト専用リクエスト」に一時切り替えて処理を継続。
- **自己修正フィードバック (Self-Correction Loop)**:
  万一 LLM の出力 JSON に構文エラーや型不整合があった場合、直ちに具体的なエラー理由をフィードバックプロンプトとして AI に送り、温度を下げて再出力させます。

## 🖼️ マルチモーダル参照画像 (Reference Image)

AI Stroke Painter はマルチモーダル Vision に対応しており、手持ちの画像やスケッチを AI に見せながら作画させることができます。

### 取り込み方法

プロンプトカード内の **「🖼️ 参照画像」** エリアを利用します：
- **ファイル選択...**: ローカルの画像ファイル（PNG, JPG, WebP）を読み込み
- **キャンバスから取得**: 現在キャンバスに描かれている内容（ラフスケッチや途中画）を取り込み
- **📋 貼り付け (`Ctrl+V`)**: クリップボードにコピーした画像を直接セット（`KisClipboard` 連携で高信頼に取得）
- 解除したいときは **「✕ 解除」** ボタンでいつでも解除できます。

### 安全で高画質な自動エンコード仕様

最新の `encodeReferenceImageBase64` エンジンにより、以下の安全・高画質化処理が自動適用されます：
- **巨大画像安全クランプ**: 長辺 16,384 px または総画素数 24 メガピクセルを超える異常画像は安全に検出・拒絶（メモリ枯渇やクラッシュを完全防御）。
- **アスペクト比維持自動スケーリング**: 最大長辺 1,024 px へスマートにリサイズし、LLM への送信ペイロードを最小化。
- **白背景アルファ合成**: PNG 切り抜き画像やラフスケッチ等の透過ピクセルを純白（`#FFFFFF`）背景へ事前に合成。JPEG エンコード時に透明部分が真っ黒に塗りつぶされてしまう問題を根絶。
- **高画質 JPEG (品質85) / PNG フォールバック**: 鮮明なディテールを維持したまま Base64 ペイロードへ自動変換。

AI が生成したイラストは、右側のレイヤーパネルに以下の役割ごとの独立レイヤーとして展開されます：

```text
[レイヤー一覧]
```

## ⚙️ 生成エンジン ＆ 接続設定

### LLM 座標ストローク描画 (Chat Completions)

推奨される標準の生成方式です。LLM にラスター画像を直接生成させるのではなく、キャンバス寸法に応じた正規化ストロークプログラム（JSON 形式）を出力させ、アプリ側が超高品質にラスタライズします。

- **対応 API**: OpenAI Chat Completions 互換エンドポイント (`/v1/chat/completions`)
- **推奨モデル**: `gpt-4o`, `o3-mini`, `deepseek-chat`, `deepseek-reasoner` など（Vision 対応モデル推奨）

### 推論モデル (Reasoning Model) への最適化

`o1`, `o3-mini`, `deepseek-reasoner` (R1) などの推論特化型モデルを自動判別し、以下の最適化を行います：
- `max_tokens` に代わり `max_completion_tokens` を自動設定（思考プロセス用の十分なトークン枠を自動確保）。
- `reasoning_effort` パラメータの自動制御。
- 出力に含まれる `<think>...</think>` ブロックの自動除去。
- 思考モデルに不適合なサンプリングパラメータ（temperature 等）の自動調整。

### セキュリティと機密情報保護

AI Stroke Painter はプロフェッショナルな環境での安全な運用のために多層防御を備えています：

1. **Windows DPAPI による暗号化保存**:
   - 「🔑 API キーをこの端末に保存する」を有効にした場合、Windows 標準の **DPAPI (Data Protection API)** により、現在の Windows ログインユーザーおよび端末に暗号学的に紐づけられた状態で保存されます。平文ファイルやレジストリに保存されることはありません。チェックを外すと直ちに完全消去されます。
2. **多重クレデンシャル自動マスキング (`redactCredentialText`)**:
   - ログウィンドウ、デバッグコンソール、UI エラー表示に出力されるテキストから、各種 API キー（OpenAI `sk-***`、Google Gemini `AIzaSy***`、Hugging Face `hf_***`、Replicate `r8_***`、GitHub PAT `gh_***`、Groq `gsk_***`、Perplexity `pplx-***`、URL クエリパラメータ `key=***`、JSON キー `"apiKey": "***"`、大文字小文字不問の `Bearer ***` トークン）を完全自動でマスキング保護。
3. **HTTP ヘッダーインジェクション防止 (`formatBearerAuthHeader`)**:
   - 認証ヘッダー送信時、改行コード（`\r`, `\n`）の自動除去および不正な Bearer 単独指定のサニタイズを徹底。

## 🔬 描画技術・品質エンジニアリング

AI Stroke Painter は、生成された座標データを美しくレンダリングするために多数の専用アルゴリズムを備えています：

1. **Centripetal Catmull-Rom スプライン曲線**:
   LLM が出力した疎な制御点同士を、尖りやくびれを生じさせない滑らかなスプライン補間曲線で結びます。
2. **単調筆圧補間 ＆ 筆圧テーパー (入り抜き)**:
   線の引き始めと引き終わりを自動で細く絞り、手描き特有の自然なインクの入り抜きを再現。
3. **Flats トラッピング (塗り拡張)**:
   線画と下塗りの間に生じがちな 1px 未満の隙間（白抜けノイズ）を防ぐため、下塗りの輪郭を数ピクセル自動拡張して線画の下に潜り込ませます。
4. **物理レンダリング (Linear HDR 32-bit + W3C Blend + 加算合成)**:
   RGBA16F / 32F 浮動小数点バッファと線形 sRGB 空間で演算。最新の加算合成 (`blendAdd`: `add`, `plus`, `linear_dodge`) に完全対応し、NaN/Inf 浮動小数点の安全ガードや変形後のサイズ整合性チェックを徹底。暗部バンディングや色相ドリフトを極限まで抑制。
5. **知覚自動修復 (Perceptual Repair)**:
   生成直後のラスタライズ画像をリアルタイム解析し、顔の輪郭からはみ出た不要な斜線や下塗りの微小な塗り残し穴を自動で検出・修復します。
6. **JSON 構文自己修復機構 (`repairJsonSyntax`)**:
   推論モデルやローカル LLM が出力途中で途切れたり、BOM・全角引用符・末尾カンマ・欠落した閉じ括弧を含む場合でも、リアルタイムで構文を自動修復して正常にパース・描画します。
7. **堅牢な null セーフティ (`KisAiStrokeCoverageRaster`)**:
   巨大キャンバスやメモリ逼迫、縮退境界に対しても安全な防御処理を施し、クラッシュを未然に防止。

### Windows テストスタック防止策

Windows CI やローカルテスト実行時に、`WerFault.exe`（Windows エラー報告）や `MessageBoxW`（CRT アサーション/エラーダイアログ）のポップアップでプロセスが対話待ちスタックするのを防ぐため、以下の多層防御が組み込まれています：
- **`KisAiTestCrashGuard`**: Win32 `MessageBoxW` / `MessageBoxA` をインラインフックしてダイアログを抑止、標準エラー出力に記録して自動継続。
- **エラーモード制御**: `WerSetFlags(WER_FAULT_REPORTING_NO_UI)`、`SetErrorMode`、`SetProcessErrorMode` でクラッシュダイアログをプロセス単位で完全無効化。
- **CRT ＆ SEH 保護**: `_set_abort_behavior`、`_set_error_mode`、`SetUnhandledExceptionFilter` でアボート時も対話ボックスを出さずに非対話終了。

## ❓ よくある質問 (FAQ) ＆ トラブルシューティング

### Q1. 起動時に「You don't have any resource bundles enabled」と表示される
**A.** 最新の配布版では、Krita のリソース初期化に必要な標準バンドル（`Krita_4_Default_Resources.bundle`）を初回起動時に自動配置・修復する機構が組み込まれています。古い実行ファイルが残っていないか確認し、最新のビルド成果物から起動してください。

### Q2. API リクエストが「401 Unauthorized」や「404 Not Found」で失敗する
**A.**
- エンドポイントの URL 末尾が正しく `/v1/chat/completions` になっているか確認してください。
- API キーの前後に余分な空白が含まれていないか確認してください。
- 詳細設定内の **「🔌 接続テスト」** ボタンを押すことで、導通状態を即座に確認できます。

### Q3. 生成したイラストを保存したい
**A.** メニューの「ファイル」→「保存」または `Ctrl + S` を押すと、全レイヤー構造や合成モードを維持したまま `.kra` ファイルとして保存できます。Web や SNS 用に画像化したい場合は「ファイル」→「エクスポート」から PNG や JPEG として書き出せます。

### Q4. 生成中に固まった・中止したい
**A.** 生成処理中は「生成ボタン」の横に **「中止」** ボタンが表示されます。これを押すと、進行中のネットワークリクエストやレンダリング処理が直ちに安全に中断されます。

### Q5. クリップボードからの画像ペーストが効かない
**A.** クリップボードにビットマップ画像データが正しくコピーされているか確認してください。スタートページでは `Ctrl + V` を押すか「📋 クリップボードから」カードをクリックすることで、画像を自動で新規キャンバス化できます。また、AI Illustration パネルの「🖼️ 参照画像」でもクリップボードからの画像取り込みが可能です。
