# 🎨 AI Stroke Painter

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](COPYING)
[![Platform: Windows](https://img.shields.io/badge/Platform-Windows%2010%2B%20(Qt6)-informational.svg)]()
[![C++: 17](https://img.shields.io/badge/C%2B%2B-17-green.svg)]()

**AI Stroke Painter** は、Krita の本格的なデジタルペイント基盤をネイティブ C++ アプリケーションとして再構成した、次世代の **AI イラスト制作統合環境** です。

従来の Krita プラグインや Python (PyKrita) スクリプトではなく、C++ ネイティブで高速に動作します。単に完成画像をキャンバスに貼り付ける一般的な画像生成ツールとは異なり、**LLM（大規模言語モデル）が生成した幾何座標と作画戦略に基づき、絵筆のストロークをレイヤー別（下塗り・陰影・線画・ハイライト・特殊効果）に物理描画** します。

生成されたイラストは完全なレイヤー構造を保持しているため、Krita の多彩なブラシ・消しゴム・投げ縄選択・カラーパレットを用いて、クリエイター自身が直感的に手動加筆・修正・仕上げを行うことができます。

## 🌟 主要な特徴

- **ネイティブ C++ 実行**: Python や PyKrita に一切依存せず、Krita の強力な描画エンジン・カラーマネジメント・元に戻す/やり直す（Undo/Redo）を直接活用。
- **レイヤー別ストローク描画**: AI が `Flats`（下塗り）、`Shading`（陰影・乗算）、`Lineart`（線画）、`Highlights`（ハイライト・スクリーン）、`FX`（効果・加算）を別々の独立したレイヤーとして自動構築。
- **自律多段階作画 (Goal モード)**: AI が自らの描画結果を視覚的に自己分析・批評し、指定した目標完成度（60–98%）に達するまで自律的にブラッシュアップを反復。
- **マルチモーダル参照画像**: ファイル、クリップボード、または現在のキャンバスから参照画像を添付し、Vision LLM にキャラクターの衣装・髪型・ポーズ・配色を直接参照させることが可能。
- **Simple / Pro 2モード UI**: ワンクリックで気軽にアイデア出しができる「かんたん (Simple)」モードと、トラッピング幅やサンプリング温度まで細かく追い込める「詳細 (Pro)」モードを瞬時に切り替え。
- **ビジュアルカード選択**: 画風（アニメ・水彩・厚塗り等7種）、構図・アングル（顔アップ・全身等4種）、照明（昼光・夕暮れ等4種）を直感的なボタンで即座に適用。
- **Krita ツールによる手動加筆**: ブラシ (`B`)、消しゴム (`E`)、スポイト (`P`)、移動 (`T`)、塗りつぶし (`F`)、投げ縄選択ツールと完全連動。
- **ローカル ＆ クラウド両対応**: OpenAI API、DeepSeek、各種互換クラウド API のほか、Ollama や LM Studio などの完全オフライン・ローカル LLM でも動作可能。
- **強固なセキュリティ**: API キーは設定ファイルへ平文保存されず、Windows DPAPI により端末および現在のログインユーザー専用に暗号化保護。

## 🚀 クイックスタート

### ワンクリック起動

Craft 環境でビルド済みのパッケージが配置されている場合、リポジトリ直下のバッチファイルからワンクリックで起動できます。

```bat
run-ai-stroke-painter.bat
```

> [!TIP]
> 手動で PowerShell から起動する場合は以下のコマンドを実行してください：
> ```powershell
> $packageBin = 'C:\CraftRoot\ai-stroke-painter\bin'
> $env:PATH = "$packageBin;C:\CraftRoot\bin;C:\CraftRoot\mingw64\bin;" + $env:PATH
> $env:QT_PLUGIN_PATH = 'C:\CraftRoot\plugins'
> $env:QT_QPA_PLATFORM_PLUGIN_PATH = 'C:\CraftRoot\plugins\platforms'
> & "$packageBin\ai-stroke-painter.exe"
> ```

### 最速チュートリアル (Simple モード)

1. アプリを起動し、右側の **AI Illustration** パネルを開きます（上部タブが「⚡ かんたん (Simple)」になっていることを確認）。
2. プロンプト欄の上に並んでいるクイックチップ（例: `美少女`, `桜風景`, `サイバー`）を押すか、テキストボックスに描きたい情景を入力します。
3. 必要に応じて「ビジュアルスタイル＆構図」からお好みのカード（例: `🌸 アニメ` + `👤 顔アップ` + `☀️ 昼光`）をクリックします。
4. **「🎨 生成してレイヤーに追加」**（または `Ctrl+Enter`）を押します。
   - キャンバスが開いていない場合は、指定サイズ（既定: 1024×1024）の新規キャンバスが自動作成されます。
5. 生成が完了すると、キャンバスとレイヤーパネルに `Flats`, `Shading`, `Lineart`, `Highlights`, `FX` が追加されます！

---

### こだわりチュートリアル (Pro モード)

1. 右側上部のタブを **「🛠️ 詳細 (Pro)」** に切り替えます。
2. **「▶ 詳細設定（エンドポイント / API キー）」** を展開し、利用する LLM の設定を入力します：
   - **エンドポイント**: `https://api.openai.com/v1/chat/completions` 等
   - **モデル**: `gpt-4o`, `o3-mini`, `deepseek-chat` など
   - **API キー**: 契約プロバイダーの API キー（Windows では「🔑 API キーをこの端末に保存する」を有効にすると安全に記憶されます）
3. パラメータを微調整：
   - **ストローク予算**: 線の細かさ・密度（既定: 500本）
   - **トラッピング幅**: 線画と下塗りの境界の白抜けを防ぐ塗り拡張幅（既定: 1.5 px）
   - **知覚自動補正 (Perceptual Repair)**: チェック推奨（下塗りの塗り残し穴や顔の斜線ノイズを自動修復）
4. **「🎨 生成してレイヤーに追加」** を実行します。

## 🎯 自律多段階作画 (Goal モード)

**Goal モード** は、AI が単なる1回の出力で終わらせず、自ら途中経過を批評・分析しながら多段階で作画を進める高度な自律描画機能です。

### 目標完成度と自律ブラッシュアップ

1. AI Illustration パネルの **「Goalモード（自律多段階作画）を有効にする」** をチェックします。
2. 以下の制御値を設定できます：
   - **基本ステップ数**: 通常の作画計画ステップ数（2〜6段階、既定: 4段階）
   - **目標完成度 (クオリティ)**: 目指す品質水準（60〜98%、既定: 85%）
   - **追加ブラッシュアップ上限**: 目標に満たない場合に自律継続する追加修正回数（1〜8段階、既定: 4段階）
3. **「🎯 Goal作画を開始」** を押すと、段階ごとに最適な作画（下地構築 → プロポーション・陰影 → 線画清書 → ハイライト・質感仕上げ）が自律実行されます。

### AI 視覚批評インスペクター

作画中、パネル内に専用の **Goal 作画インスペクター** が表示されます：
- **作画フェーズ**: 現在の進行状態（構図、下塗り、陰影、ハイライト等）
- **🎯 着目領域**: AI が現在重点的に描き加えている部位（例: 「顔の輪郭と目元」「髪の陰影」）
- **自律完成度ゲージ**: AI が自己評価した現在の完成度パーセンテージ
- **AI 視覚批評・自己分析**: 「線画のコントラストは良好だが、瞳のハイライトと右頬の影のなじみが不足しているため追加補正する」等の思考内容をリアルタイム表示

### 人間と AI の協調作画（ステップごと一時停止）

- **「段階ごとに一時停止（手動加筆・確認を待つ）」** にチェックを入れると、1ステップ描画するごとに AI が待機状態に入ります。
- ユーザーは Krita のブラシで線を手動修正したり、色を塗り足したりしてから、**「▶ 次のステップへ進む」** を押せます。AI は人間の手動加筆を反映したキャンバスを認識して次の作画へ進みます。
- 十分な品質に達したと感じた場合は、いつでも **「🏁 ここで完成」** を押して早期確定が可能です。

## 🖼️ 参照画像 (Reference Image) の活用

AI Stroke Painter はマルチモーダル Vision に対応しており、手持ちの画像やスケッチを AI に見せながら作画させることができます。

1. プロンプトカード内の **「🖼️ 参照画像」** エリアを利用します：
   - **ファイル選択...**: ローカルの画像ファイル（PNG, JPG, WebP）を読み込み
   - **キャンバスから取得**: 現在キャンバスに描かれている内容（ラフスケッチや途中画）を取り込み
   - **📋 貼り付け**: クリップボードにコピーした画像を直接セット
2. 設定されると、小さなサムネイルと解像度情報が表示されます。
3. リクエスト送信時、画像が自動的に最適サイズへエンコードされ、Vision LLM へ送信されます。AI はプロンプト指示と参照画像の「キャラクターの外見」「衣装」「髪型」「カラーパレット」「構図」を深く分析し、整合性の取れたストロークを生成します。
4. 不要になったら **「✕ 解除」** ボタンでいつでも解除できます。

## 🎨 ビジュアルスタイル ＆ プロンプト支援

### ビジュアルスタイルカード

ドロップダウンを開いて文字を探す手間を省き、ワンクリックで画風や構図を指示できます。

- **画風スタイル (7種)**: `🖋️ 純線画`, `🌸 アニメ`, `💧 水彩`, `🖌️ 厚塗り`, `⚡ サイバー`, `✒️ インク`, `🖋️ 細密画`
- **構図・アングル (4種)**: `👤 顔アップ`, `👚 バスト`, `👗 全身`, `📐 煽り/俯瞰`
- **照明・ムード (4種)**: `☀️ 昼光`, `🌇 夕暮れ`, `🌙 月夜`, `⚡ 逆光`

### ✨ AI 推敲 (Prompt Expander)

「森の少女」や「夕暮れの街」といった短いキーワードしか思い浮かばない場合、プロンプト欄右上の **「✨ AI推敲」** ボタンを押します。
接続されている LLM が、アニメ・イラスト向けの具体的かつ魅力的な情景描写（光の方向、衣装の細部、髪のなびき、色彩設計）を含んだ豊かなプロンプトへと自動で展開・書き換えます。

### 🎨 前景色同期

Krita のカラーセレクターやパレットで「この色を使いたい」という色を選び、**「🎨 前景色」** ボタンを押します。
現在アクティブなカラーコード（例: `#38bdf8`）と色名がプロンプトの末尾に配色指定として自動追記されます。

### 🖼️ 生成履歴ギャラリー

パネル下部には、直近で生成したイラストのサムネイルが自動的に並びます。
過去のサムネイルをクリックすると、その生成時に使ったプロンプトや各種設定が瞬時に復元されるため、試行錯誤やパラメータ比較を快適に行えます。

## 🖌️ 手動加筆 ＆ Krita 連携機能

AI Stroke Painter は、AI が生成した後の **「人間の手による仕上げ」** を徹底的に重視しています。

### ショートカットキー一覧

| キー | ツール・操作 | 機能説明 |
| :--- | :--- | :--- |
| `Ctrl + Enter` | **イラスト生成** | 現在のプロンプトと設定で生成を開始 / 次のステップへ進行 |
| `B` | **フリーハンドブラシ** | ペンやブラシプリセットを使ってキャンバスへ直接描画 |
| `E` | **消しゴム切替** | 現在のブラシを消しゴムモードへ反転切替 |
| `P` | **スポイト** | キャンバス上の色をクリックして前景色に抽出 |
| `T` | **移動ツール** | レイヤーの描画内容をキャンバス上で移動・配置変更 |
| `F` | **塗りつぶしツール** | クリックした領域を一括でベタ塗り |
| `Ctrl + Z` | **元に戻す (Undo)** | 直前のストロークや AI 生成レイヤーを1手戻す |
| `Ctrl + Shift + Z` | **やり直す (Redo)** | 取り消した操作をやり直す |
| `Ctrl + S` | **保存** | 現在の作業状態を `.kra`（Krita 形式）で保存 |
| `Ctrl + Shift + S` | **別名で保存** | 新しいファイル名を指定して保存 |

### 5層レイヤー構造の仕組み

AI が生成したイラストは、右側のレイヤーパネルに以下の役割ごとの独立レイヤーとして展開されます：

```text
[レイヤー一覧]
├── 🎨 AI: Highlights   (合成: スクリーン / 白飛びを抑えた柔らかな光・天使の輪・瞳のハイライト)
├── 🎨 AI: Lineart      (合成: 標準または乗算 / 精緻なスプライン曲線による輪郭・目鼻口・髪の主線)
├── 🎨 AI: Shading      (合成: 乗算 / 光源ベクトルに基づく影・立体感のシェーディング)
├── 🎨 AI: Flats        (合成: 通常 / トラッピング拡張された隙間のないベース下塗り)
└── 🎨 AI: FX           (合成: 加算 / パーティクル・オーラ・背景のグラデーション光)
```

それぞれのレイヤーは独立しているため、「線画レイヤーだけ残して塗りを自分でやり直す」「影の色相や不透明度だけをスライダーで変更する」といった自由自在な編集が可能です。

## ⚙️ 生成エンジン ＆ 接続設定

### LLM 座標ストローク描画 (Chat Completions)

推奨される標準の生成方式です。LLM にラスター画像を直接生成させるのではなく、キャンバス寸法に応じた正規化ストロークプログラム（JSON 形式）を出力させ、アプリ側が超高品質にラスタライズします。

- **対応 API**: OpenAI Chat Completions 互換エンドポイント (`/v1/chat/completions`)
- **推奨モデル**: `gpt-4o`, `o3-mini`, `deepseek-chat` など（Vision 対応モデルを強く推奨）

### 各種プロバイダー設定例

#### 1. OpenAI 公式
- **エンドポイント**: `https://api.openai.com/v1/chat/completions`
- **モデル**: `gpt-4o` または `o3-mini`
- **API キー**: `sk-...`

#### 2. DeepSeek
- **エンドポイント**: `https://api.deepseek.com/v1/chat/completions`
- **モデル**: `deepseek-chat`
- **API キー**: `sk-...`

#### 3. Ollama (ローカル完全オフライン実行)
- **エンドポイント**: `http://localhost:11434/v1/chat/completions`
- **モデル**: `llama3.2-vision` または `qwen2.5-coder`
- **API キー**: （不要・空欄のままで可）

#### 4. LM Studio (ローカル実行)
- **エンドポイント**: `http://localhost:1234/v1/chat/completions`
- **モデル**: LM Studio でロードしたローカルモデル名
- **API キー**: （不要・空欄のままで可）

> [!NOTE]
> 外部ホストへの通信は安全のため HTTPS が必須です。ローカル開発環境（`localhost`, `127.0.0.1` 等）に限り HTTP 接続が許可されます。

### 画像モデル API (DALL-E) ＆ ローカルオフラインモード

- **画像モデル API (DALL-E)**: `/v1/images/generations` 互換のエンドポイントから画像を取得して新規レイヤーに追加します。
- **ローカル座標ストローク描画**: ネットワーク接続や API キーが一切不要で、決定論的なアルゴリズムによりオフラインで座標ストロークを生成・描画します。
- **ローカル・コンセプトスケッチ**: オフラインで即座にスケッチ画像を生成します。

### セキュリティと API キーの DPAPI 暗号化保護

- API キーは平文でレジストリや設定ファイルに保存されることはありません。
- 「🔑 API キーをこの端末に保存する」を有効にした場合、Windows 標準の **DPAPI (Data Protection API)** により、現在の Windows ログインユーザーおよび端末に暗号学的に紐づけられた状態で保存されます。
- チェックを外すと、保存されたキーは直ちに完全消去されます。

## 🔬 描画技術・品質エンジニアリング

AI Stroke Painter は、生成された座標データを美しくレンダリングするために多数の専用アルゴリズムを備えています：

1. **Centripetal Catmull-Rom スプライン曲線**:
   LLM が出力した疎な制御点同士を、尖りやくびれを生じさせない滑らかなスプライン補間曲線で結びます。
2. **単調筆圧補間 ＆ 筆圧テーパー (入り抜き)**:
   線の引き始めと引き終わりを自動で細く絞り、手描き特有の自然なインクの入り抜きを再現。
3. **Flats トラッピング (塗り拡張)**:
   線画と下塗りの間に生じがちな 1px 未満の隙間（白抜けノイズ）を防ぐため、下塗りの輪郭を数ピクセル自動拡張して線画の下に潜り込ませます。
4. **物理レンダリング (RGBA16F + W3C Blend)**:
   Pro 設定で有効化可能。線形 sRGB 空間で浮動小数点演算を行い、暗部バンディング（色階調の段差）や色相ドリフトを極限まで抑えます。
5. **知覚自動修復 (Perceptual Repair)**:
   生成直後のラスタライズ画像をリアルタイム解析し、顔の輪郭からはみ出た不要な斜線や下塗りの微小な塗り残し穴を自動で検出・修復します。

## ❓ よくある質問 (FAQ) ＆ トラブルシューティング

### Q1. 起動時に「You don't have any resource bundles enabled」と表示される
**A.** 最新の配布版では、Krita のリソース初期化に必要な標準バンドル（`Krita_4_Default_Resources.bundle`）を初回起動時に自動配置・修復する機構が組み込まれています。古い実行ファイルが残っていないか確認し、最新のビルド成果物から起動してください。

### Q2. API リクエストが「401 Unauthorized」や「404 Not Found」で失敗する
**A.**
- エンドポイントの URL 末尾が正しく `/v1/chat/completions` になっているか確認してください。
- API キーの前後に余分な空白が含まれていないか確認してください。
- 詳細設定内の **「🔌 接続テスト」** ボタンを押すことで、導通状態を即座に確認できます。

### Q3. 生成したイラストを保存したい
**A.** メニューの「ファイル」→「保存」または `Ctrl + S` を押すと、全レイヤー構造や合成モードを維持したまま `.kra` ファイルとして保存できます。Web や SNS 用に画像化したい場合は「ファイル」→「エクスポート」から PNG や JPEG として書き出せます。

### Q4. 生成中に固まった・中止したい
**A.** 生成処理中は「生成ボタン」の横に **「中止」** ボタンが表示されます。これを押すと、進行中のネットワークリクエストやレンダリング処理が直ちに安全に中断されます。
